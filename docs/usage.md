# USCWIFI 维护助手

适用：Windows 10/11 x64、开放式校园 Wi-Fi `USCWIFI`、认证地址 `210.43.112.9`。开发环境为 Windows 10，Windows 11 兼容性通过用户反馈持续验证。

## 第一次使用

1. 将 `USCWIFI_Guard.exe` 放在准备长期保留的位置，再双击运行。无需安装 Python，也无需管理员权限。
2. 在程序窗口输入校园网账号、密码，勾选“登录 Windows 后自动启动”，点击“保存并开始”。账号密码不需要发给任何人。
3. 观察状态。当前已经登录时，程序会确认在线，不会再次提交密码。真正的自动登录需要在下次校园网掉线或重新开机、尚未认证时验证。
4. 点击“隐藏到托盘”或关闭窗口，程序会继续维护。双击右下角托盘图标可重新打开窗口；图标可能藏在折叠区域中。

程序在保存配置时才登记自动启动。自动启动发生在登录 Windows 后，不在 Windows 登录界面之前。如果以后移动或重命名程序，请在新位置运行并再次点击“保存并开始”，以更新启动路径。

## 自动维护行为

- 每 0.5 秒检查本机无线状态；认证状态约每 3 秒查询一次。保存配置或恢复维护后立即唤醒检查。
- 无线未连接时，尝试通过本机已有的 `USCWIFI` 无线配置连接；请保持 Wi-Fi 开关开启。首次使用时需在 Windows 中手动连接一次以保存配置。
- 已连 USCWIFI 时先查认证状态，认证接口确认未登录时直接认证，不先等待外网探测。加载实际认证页并复用同一网页会话，按学校网页的字段映射提交参数；不把普通 ip 参数强行作为 userIpv4 认证目标。
- 已连接其他 Wi-Fi 时待命。实体有线网卡已连接且具有 IPv4 和网关时，优先检查有线；识别到学校认证页的 HTTP 跳转后复用保存的账号密码认证。普通有线网络不提交账号。
- 有线认证请求绑定有线地址，提交前检查连接和路由；不需要无线网卡或 WLAN 服务。多条实体有线连接、认证路由经其他网卡、或未识别到学校跳转时等待处理。VPN、虚拟网卡和断开但保留地址的网卡不作为实体有线连接。
- 已认证但 Internet 不通时等待恢复，不反复注销或提交密码。
- 认证成功后约 0.5 秒开始查询认证结果；重复提交至少间隔 8 秒。网络、认证服务暂不可用时延迟重试，最长间隔 1 分钟。
- 直接通过 Windows 网络接口实时读取 IP、网卡硬件标记和连接状态，不依赖 PowerShell 分类缓存；读取失败时稍后重试，不将未知网卡直接判作其他网络。联网探测只在已认证后执行，正常联网时最多每分钟一次。
- 密码校验失败、登录拒绝、验证码、强制改密或未知认证响应会停止自动登录并显示提醒。登录拒绝也可能是欠费、设备数量限制等情况，程序不会擅自踢掉其他设备。

程序不主动关闭其他网络连接，不修改 Windows 的全局网络检测设置，也不自动退出当前校园网账号。

## 暂停、恢复与人工处理

- “暂停维护”会停止后续连接和认证操作；已经发出的网络请求可能需要等待超时。
- 人工处理完成后，点击“恢复维护”或“保存并开始”。
- 连续三次提交认证后仍未确认本机在线，会停止自动登录。请在故障电脑点击“导出诊断”，提供生成的文本，以便检查服务器的返回状态；该文本不包含保存的账号密码、cookie 或完整配置。
- “打开登录页”直接打开学校的账号认证页 `http://210.43.112.9/tpl/default/login_account.html`，携带 `nasId=1` 和本机当前无线 IPv4 地址，不依赖 Windows 网络检测网页跳转。已经认证时页面会显示在线信息，未认证时显示登录表单。无法确定当前无线地址时省略 IP 参数，不复用旧 IP。
- 修改已保存账号时必须填写对应密码。同一账号的密码框留空表示保留原密码。
- “退出程序”立即结束本次维护；如果启用了自动启动，下次登录 Windows 时仍会启动。

## 保存的数据与移除方式

配置保存在 `%LOCALAPPDATA%\USCWIFI维护助手\settings.json`。账号、密码整体使用 Windows DPAPI 加密，绑定当前 Windows 用户。程序运行时仍需在内存中使用凭据，不能将此功能理解成防范当前 Windows 账户被完全控制。

状态日志为同一目录的 `status.log`，最多保留三个约 256 KB 的文件，不记录账号、密码、接口原始响应或浏览器 cookie。认证通信遵循学校现有的 HTTP 接口。

不再使用时：取消勾选“登录 Windows 后自动启动”，点击“保存并开始”，然后退出程序并删除 EXE。如需清除保存的凭据，退出后删除上述数据目录。源文件 `campus_guard.py` 供查看和修改；日常使用只需 EXE。
